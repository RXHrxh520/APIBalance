# 隐私与安全

> 密钥怎么存、请求发到哪、备份怎么加密。由原说明书原样迁移。

## 概览：四条承诺

- **密钥存储**：Android Keystore 生成 AES-256 密钥，AES/GCM 加密后存 SharedPreferences，明文不落盘（自动登录 Key 与多账户 Key 均加密）
- **网络**：仅请求各家官方余额 API（api.deepseek.com / api.moonshot.ai / open.bigmodel.cn / api.anthropic.com）与 GitHub 版本检查；TLS 证书校验恒开启
- **备份包**：导出前用你设定的密码加密，恢复需同一密码；恢复代码修改需先验证锁屏密码
- **无任何私人服务器**，无广告 SDK，无第三方统计

## 安全中心（App 内 20 项体检）

- **签名校验**：对比**内置官方证书指纹**，被重新签名的仿冒包会直接报出实际指纹
- **APK 完整性**：校验运行中的代码是否来自本安装包
- **安装来源**：显示真实包名，读不到就明说侧载
- **环境项**：悬浮窗、调试器、Root、模拟器、系统版本等逐项体检
- **备份与恢复**：导出 `.bin` / `.zip`（密码加密），还原含 API Key；恢复代码修改前需先通过锁屏密码验证

## 用户最常担心的四件事

**「我填的 Key 会不会被作者看到？」**
看不到。Key 用系统级加密后存在手机本地，App 直接把请求发给各家官方域名，中间没有任何作者服务器。作者能看到的和你一样——只有 GitHub 上那些公开的下载次数。

**「需要 root 或者装一堆东西吗？」**
不需要。普通 APK 安装即可，不申请 root，不装证书，不改系统设置。

**「手机丢了怎么办？」**
App 支持指纹 / 密码锁，并可设置离开 1 / 5 / 15 分钟自动锁；配合"隐藏余额"（以 `****` 显示）和"禁止截屏"，别人拿到手机也看不到具体数额。最坏情况下，去各家控制台把 Key 作废即可，损失可控。

**「怎么确认我下的包是真的？」**
1. 只从本仓库 Releases 下载；
2. 每个 Release 描述里都有该版本的 **SHA-256**，可与下载下来的文件比对；
3. App 内的安全中心会拿运行时的签名与**内置官方证书指纹**比对，仿冒包会直接报出实际指纹。

## 权限与数据说明

- 只申请查询余额、网络访问、通知、指纹解锁等必要权限，不申请通讯录、短信、位置；
- 不引入任何统计 SDK、广告 SDK、崩溃上报第三方服务；
- 历史记录、备份包全部保存在本机，导出到「下载」目录时由你手动触发。
