# 路线图

这里说明项目**接下来想做什么、不做什么**，避免重复提同样的建议。排序不代表承诺，实际以 Release 为准。

## 正在做

- **服务商覆盖**：按用户实际在用的服务商逐个补，不追求数量堆砌。
- **多语言**：中文 / English / 繁體中文 / 萌语 / 世界语 五套文案。
- **无障碍与可读性**：字体大小分级、深色模式全覆盖、对比度调整。

## 计划做

- **截图与图文说明**：文档站补上界面截图，让非开发者装之前就能看清长什么样。
- **构建产物**：除通用包外，提供按架构区分的构建包说明（大文件不进仓库，走群文件）。
- **导出格式增强**：历史数据支持更多统计维度（按服务商 / 按月的对比）。
- **错误提示人性化**：把服务商原文错误码翻译成人话，直接给出处理建议。

## 明确不做

- **不做请求转发 / 代理池 / 负载均衡**：本项目只读余额，不碰你的对话请求，不做多 Key 轮询转发。
- **不做云同步 / 账号体系**：数据只在本机，靠导出的备份包迁移，不上传任何服务器。
- **不接广告、不接第三方统计 SDK**：保持零埋点、零广告。
- **不做收费版**：BSD 3-Clause，永久开源免费。
- **不做需要备案的国内托管**：文档站走 GitHub Pages。

## 想提建议

到仓库 [Discussions](https://github.com/RXHrxh520/APIBalance/discussions) 或 [Issues](https://github.com/RXHrxh520/APIBalance/issues) 提，说明使用场景比只说功能名更有用。
