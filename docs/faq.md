# 常见问题（FAQ）

> 面向普通用户。遇到问题先看这里，再提 Issue 或到 QQ 群问。

## 一、安装相关

### 提示"签名不一致 / 应用未安装"，装不上
官方包使用作者固定证书签名。三种情况：
1. **以前装过别的版本/别人改过的包**：先卸载旧版再装。⚠️ 卸载会清除本地密钥，**先做一次备份**（设置 → 备份与恢复）。
2. **你自己用源码编译的包**：签名不同，无法覆盖安装官方版，属正常现象，二选一即可。
3. **手机厂商拦截**：在"安装未知来源应用"里对本浏览器/文件管理器放行。

### 更新后数据还在吗
在。覆盖安装保留账户、Key 和设置。

### 支持哪些安卓版本
Android 8.0（API 26）及以上。包名 `asia.rxh.apibalance`。

## 二、查询相关

### 余额显示 0 或者 -0.00
这是老版本的显示 bug，v1.5.3 已修复为真实欠费值（负数照实显示）。升级到最新版即可。

### 报 401 / 403（鉴权失败）
- Key 复制时**多了空格或换行**，删掉首尾空白再试；
- Key 已过期或被删除，去对应服务商控制台重新生成；
- 部分服务商的接口对地区有限制，需要走代理（App 设置里有"网络代理"）。

### 报 429（请求太频繁）
被服务商限流了。等 1~5 分钟再查；并把"定时自动刷新"的间隔调长一些（比如从 60 秒改到 300 秒以上）。

### 套餐配额为什么显示"5 小时剩余 / 每周剩余"，不是金额
Kimi Code、GLM Coding、Codex 这类是**订阅制套餐**，官方接口返回的是配额而不是钱。App 按接口真实含义展示，**不会把配额伪装成金额**。

### 火山方舟为什么用 AccessKey / SecretKey
官方余额接口要求 AK/SK 签名，不是普通 API Key，按控制台给的填即可。

### 余额数据和官方后台不一致
App 只读各家**官方接口**返回的值，不做任何推算。若不一致，通常是：接口有缓存延迟、或你的账户有多个子账户/工作区，官方后台显示的是别的账户。以官方后台为准。

### 汇率不准
汇率是**离线近似值**，只用于换算显示，不参与任何计算。想要准确汇率：设置里填一个自定义汇率 JSON 地址（约定 `{"usd_cny": 7.2}`）。

## 三、后台与通知

### 关掉 App 后不再提醒 / 定时刷新失效
安卓省电策略会杀掉后台任务。逐项检查：
1. 设置 → 应用 → APIBalance → 电池 → 改为"不限制/允许后台活动"；
2. 允许"自启动"（部分国产系统在手机管家里单独开关）；
3. 多任务界面里给本 App 加锁，避免被一键清理。

### 静音时段没生效
静音只影响**提醒声音**，不影响余额查询和记录。检查时间段的起止是否填反。

## 四、数据与隐私

### 我的 API Key 会被上传吗
不会。密钥用 Android Keystore 生成的 AES-256 密钥加密后存在本机，**不经过任何第三方服务器**，App 只直接请求各家官方接口。详见 [隐私与安全](security.md)。

### 换手机怎么迁移
设置 → 备份与恢复 → 导出 `.bin` / `.zip`（密码加密，含 API Key）→ 新手机导入同一密码恢复。

### 历史记录能存多久
本地保留最近 **200 条**余额记录，可按服务商筛选、按近 7/30/90 天过滤，支持导出 CSV / JSON。

### 为什么搜不到原来的名字
本项目原名 **DeepseekBalance**（DS 余额查询），后更名为 **APIBalance** 并扩展到 8 家服务商。旧版链接会失效，认准本仓库地址。

### 是免费的吗
永久开源免费（AGPL-3.0）。如果你是**付费购买**的，请找卖你的人退款。

### 能加新的服务商吗
可以。提 Issue 说明服务商名称和余额接口文档，或在 QQ 群反馈。

### 想反馈 Bug
- 提 Issue（仓库已内置 Bug / 功能建议模板）；
