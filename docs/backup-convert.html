--- layout: default title: 备份升级工具 · APIBalance description: 把旧版加密的 APIBalance 备份包在浏览器本地转换成新版格式，文件不上传任何服务器。 permalink: /backup-convert.html --- # 备份升级工具 > **转换在你的浏览器里完成，文件不会上传到任何服务器。** 这个页面没有任何上传接口，断网也能用；旧的加密算法只在你的电脑/手机本地跑一次，用完即弃。 ## 这是干什么的 新版本把备份改成了**一套**格式（PBKDF2-HMAC-SHA256 60 万次 + AES-256-GCM，128 位认证标签，AAD 绑定格式元数据），App 里不再内置旧算法。你手上如果是旧版本导出的备份包，先用这里转一下，再回 App 恢复即可。 - 支持：旧 CBC 格式（v1，`.bin`）、过渡 GCM 格式（v2，`.bin` 或 `.zip`） - 输出：新版格式（v3，`.bin`），App 的「恢复」直接选它 - 已经是 v3 的文件：会提示无需转换

口令只在内存里参与 KDF 计算，不落盘、不进日志、不发网络请求。转换完成后刷新页面即可清空。 页面加载的是 /assets/js/backup-convert.js，你可以自己打开看，全程用的是浏览器自带 WebCrypto。

## 参数（和 App 逐字节一致） | 项目 | 取值 | | --- | --- | | 密钥派生 | PBKDF2-HMAC-SHA256，600000 次，256 位 | | salt | 每次转换随机 16 字节 | | 加密 | AES-256-GCM，128 位 tag | | nonce | 每次转换随机 12 字节，绝不复用 | | AAD | `RXHBK3` + 版本 + KDF 编号 + 迭代次数（4 字节大端）+ salt | | 完整性 | 明文尾部保留 App 的 HMAC-SHA256 签名与 `APIBAL01` 标记，转换只换加密壳、不动内容 | ## 常见问题 **转换失败提示「口令错误或文件损坏」？** 优先确认口令：旧 CBC 格式没有认证标签，口令错时只能靠尾部 HMAC 签名判断，所以报错会统一成这一句。 **需要联网吗？** 不需要。转换过程零网络请求。 **转换后的文件还是打不开？** 确认 App 已是包含 v3 格式的新版本；如果仍失败，把文件留在本机，去仓库提 issue 时附上「文件大小 + 转换页输出」，不要附文件本体和口令。 返回：[隐私与安全](security.html) · [安装与常见问题](faq.html)
