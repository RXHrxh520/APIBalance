# 错误码速查

查询失败时，界面会显示服务商返回的原始状态码或提示。按下表对照处理，比笼统说「查不出来」更快定位。

| 现象 | 大概率原因 | 处理办法 |
|---|---|---|
| **401 Unauthorized** | Key 失效、复制时带了空格或换行、Key 与所选服务商不匹配 | 重新从服务商后台复制 Key（只复制字符本身，别带 `Bearer` 前缀）；确认服务商与 Key 来源一致 |
| **403 Forbidden** | Key 权限不足（子账号 / 只读 Key / 未开通对应接口）、账号被风控 | 换主账号的 Key，或到服务商后台确认该 Key 有余额查询权限 |
| **404 / 405** | 服务商接口改版，端点失效 | 更新到最新版本；仍失败请提 Issue 并附上服务商与时间 |
| **429 Too Many Requests** | 请求过于频繁，触发限流 | 把「定时自动刷新」间隔调大（建议 ≥ 30 分钟）；等几分钟再手动查 |
| **5xx** | 服务商服务端异常，与 Key 无关 | 等官方恢复，稍后重试 |
| **超时 / 连接失败** | 网络不稳、DNS 异常、开启了系统代理 | 先关掉代理试一次；在「网络」设置里把超时调大、重试次数调高 |
| **证书校验失败（SSL）** | 中间网络做了拦截，或系统时间错误 | 校准手机时间；换网络（移动数据 vs Wi-Fi）复测 |
| **显示 -0.00 或 0.00 但实际欠费** | 旧版本的四舍五入问题 | 升级到 v1.5 及以上，欠费会显示真实负值 |
| **套餐显示「金额」但其实是配额** | 服务商返回的是配额单位 | 这是按接口真实含义展示，套餐类会在卡片上标注「5 小时 / 每周剩余」 |
| **后台不提醒** | 通知权限未给、被系统省电策略杀掉、静音时段生效 | 检查通知权限 → 关掉对该 App 的电池优化 → 查看「静音时段」设置 |
| **覆盖安装失败（签名冲突）** | 当前装的是自编译版或第三方改包，签名与官方不同 | 先卸载旧包再装官方版；安全中心会直接报出实际证书指纹 |
| **应用内更新装不上** | 未允许「安装未知应用」 | 系统设置里给本 App 开启该开关，或直接到 Releases 下载 |

## 提 Issue 时请附上

1. 出错的服务商名称与 App 版本号（设置 → 关于）；
2. 状态码或界面提示原文（**打码后再截图，别贴出 API Key**）；
3. 用的网络环境（Wi-Fi / 移动数据 / 是否开代理）。
